# RFC 032 质检框架 QIF

## 背景

QIF（Quality Inspection Framework）是 Arc 原生质检体系。**当前稳定面为 L1 单元测试**（`[Fact]`/`[Theory]` + `Assert.*`）；RFC 愿景中的七层（集成 / E2E / 性能 / 属性 / 快照 / 契约）为分层职责图，**不宣称已实现**。核心立场与语言反射决策一致：**Arc 永久剔除反射**，测试发现走编译期 AttributeTable 收集 + GenerateTo/Source Generator 生成 registry（信条「代码即数据」），而非运行时反射扫描。`arc test` 是默认验证入口，也是质量闸门（信条「安全在编译期完成——可证伪质量」）。

## 设计决策

### 1. 测试发现与执行模型

| 项 | 决策 |
|----|------|
| 发现 | 编译期 AttributeTable 收集 + GenerateTo/Source Generator 生成 registry（无反射） |
| 执行 | 合成 `__QifTestHost.Main()` 入口 → 编译为静态可执行文件并运行 |
| 断言 | XUnit 风格 `Assert.*` |
| 默认调度 | **串行**（确定性优先） |
| 可选并行 | `--parallel`：对标 xUnit 子集——**集合间并行、集合内串行** |

`arc test` 对标 `dotnet test`：扫描源码 AST 收集 `[Fact]`/`[Theory]` 测试方法，自动生成 `__QifTestHost.Main()` 入口，完整编译后运行。

### 2. `arc test` 命令

| 选项 | 含义 | 默认 |
|------|------|------|
| `--project <PATH>` | 与 `PROJECT` 等价 | — |
| `-c` / `--configuration <CONFIG>` | 构建配置 `Debug` / `Release` | `Debug` |
| `-r` / `--runtime <RUNTIME>` | 目标运行时标识 | 宿主 triple |
| `-o` / `--output <DIR>` | 输出目录 | `bin/<config>/` |
| `--no-build` | 跳过编译直接运行已有测试二进制 | — |
| `--verbosity <LEVEL>` | 日志级别 | `normal` |
| `--filter <EXPRESSION>` | XUnit 风格过滤（`Field~Value` + `\|`/`&`/`!`） | — |
| `--namespace <NS>` | 按命名空间前缀选择（与 filter AND） | — |
| `--kind <KIND>` | 按 Kind 选择（`Fact`/`Theory`/…；与 filter AND） | — |
| `--list-tests` | 列出所有测试（不执行） | — |
| `--list-format <FMT>` | 列表格式 `text` / `json` | `text` |
| `--logger <LOGGER>` | 输出格式 `human` / `json` / `junit` | `human` |
| `--parallel` | 启用集合级并行（见 §8） | 关闭（串行） |
| `--max-parallel <N>` | 最大并发度（仅配合 `--parallel`；`0`=不限） | 见 `[qif].max_parallel` |
| `--timeout <MS>` | 默认单测超时毫秒（`0`=不限） | `[qif].default_timeout` |
| `--fail-on-skip` | Assert.Skip 计 Skipped 时非零退出 | 关闭 |
| `--coverage` | 覆盖率插桩 → lcov（**尚未落地**，见 §9） | 关闭 |
| `-g` / `--debug` | 发射 DWARF 5 调试信息 | — |
| `--ani-native-lib <DIR>` | Native 库搜索路径（可重复） | — |
| `--obj-dir <DIR>` | 中间产物目录 | `obj/<config>/` |

```bash
arc test examples/UnitTest                              # 默认串行
arc test examples/UnitTest -c Release --filter "FullyQualifiedName~AssertTests"
arc test examples/UnitTest --list-tests
arc test examples/UnitTest --logger junit
arc test examples/UnitTest --parallel --max-parallel 4
arc test examples/UnitTest --namespace UnitTest.QIF --kind Fact
```

### 3. 测试特性

| 特性 | 语义 |
|------|------|
| `[Fact]` | 无参测试方法 |
| `[Theory]` | 参数化测试方法，配合 `[InlineData]` 提供多组入参 |
| `[Fact] async` | 异步测试方法，经 EventLoop 调度运行；**含任一 async Fact/Theory 时整套强制串行**（`Parallel.For` 回调无法 `await`） |
| `[Fact(Timeout=N)]` / `[Theory(Timeout=N)]` | 单测超时毫秒；`0`/缺省 → 套件默认（CLI `--timeout` / `[qif].default_timeout`）；正值覆盖套件默认 |
| `[Collection("name")]` | 类级集合边界（对标 xUnit）；并行时同名集内串行、异名集间并行；未标注时每类自成隐式集合 |
| `[Trait("k","v")]` | 过滤/报告用标签 |
| `[Order(N)]` | 执行序（升序；对标 xUnit Collection 内排序习惯） |
| `[Fact(Skip="…")]` | 属性级跳过——**默认入口禁止**；宿主记 `FactSkipped` 并硬失败退出 |
| 构造注入 `IQIFOutput` | 对标 xUnit `ITestOutputHelper`（类 ctor 注入）；**非**完整 `IClassFixture`/`ICollectionFixture` |
| `IQIFSetup` / `IQIFTeardown` | 每方法前后钩子（对标构造函数 / `IDisposable` 的显式面） |

```arc
[Fact]
public void EqualPasses() {
    Assert.Equal(2, 1 + 1);
}

[Theory]
[InlineData(1, 2, 3)]
[InlineData(10, 20, 30)]
public void AddWorks(int a, int b, int expected) {
    Assert.Equal(expected, a + b);
}
```

### 4. `Assert.*` 断言面

| 断言 | 语义 |
|------|------|
| `Assert.Equal` / `NotEqual` | 值相等（`int`/`long`/`string`/`bool`；`double` 带 Δ） |
| `Assert.Same` / `NotSame` | 引用同一性（对标 xUnit Same/NotSame） |
| `Assert.True` / `False` | 布尔断言（可带 message） |
| `Assert.Null` / `NotNull` | 可空断言 |
| `Assert.Throws(name, Action)` / `Throws(code, name, Action)` | 断言抛出（非泛型面；`Throws<T>` 因 MIR 限制延后） |
| `Assert.DoesNotThrow` | 断言不抛 |
| `Assert.All` / `Any` / `Single` / `Single(pred)` | 序列谓词 / 单元素 |
| `Assert.SequenceEqual` / `Contains` / `DoesNotContain` / `Empty` / `NotEmpty` | 集合与子串 |
| `Assert.StartsWith` / `EndsWith` | 字符串前后缀 |
| `Assert.InRange` / `NotInRange` / `Greater*` / `Less*` | 比较与区间 |
| `Assert.IsType(Type, Type)` | `typeof` 身份相等（诚实子集；无 `GetType()` 反查） |
| `Assert.IsException(object)` | `is Exception` 专用路径 |
| `Assert.Fail` / `Skip` | 硬失败 / 运行时跳过（`QIF_SKIP:`） |

**有意不支持 / 延后**：泛型 `Throws<T>` / `IsType<T>(object)`（MIR「泛型+委托+is T」）；任意 object 运行时类型反查（永久剔除 `GetType()`）；`IClassFixture`/`ICollectionFixture` 全生命周期 DI；`--batch`/`--only`；L2–L7 执行器。

### 5. 七层测试（愿景 / 非完备宣称）

QIF **面向**七层测试职责递进；**仅 L1 单元测试为当前稳定实现面**：

| 层 | 内容 | 面 |
|----|------|-----|
| 单元测试 | 单函数/单类行为，`[Fact]`/`[Theory]` + `Assert.*` | **稳定面（L1）** |
| 集成测试 | 跨组件协作 | 不在本实现面内 |
| E2E 测试 | 端到端完整链路 | 不在本实现面内 |
| 性能基准 | 基准/回归 | 不在本实现面内 |
| 属性测试 | 基于性质/随机生成验证 | 不在本实现面内 |
| 快照测试 | 输出快照比对 | 不在本实现面内 |
| 契约测试 | 接口/协议契约验证 | 不在本实现面内 |

Kind 枚举可携带 L2–L7 标签供过滤，**不等于**各层执行器/基础设施已交付。

### 6. 跳过机制 QIF_SKIP

`QIF_SKIP`（`Assert.Skip`）是唯一受认可的**运行时**跳过标记。默认入口**不允许属性 Fact-Skip**（`[Fact(Skip=…)]`）——回归不靠 Skip 粉饰；属性 Skip 一经收集即 `RecordFactSkip`，宿主 `ShouldFailExit` 恒非零。

- **Assert.Skip**：计 `Skipped`；默认仍 exit 0（契约自测需要）。`--fail-on-skip` / `[qif].fail_on_skip=true` 时 Assert.Skip 亦非零退出。
- **产品判据**：权威套件零属性 Fact-Skip；Assert.Skip 仅限框架契约自测，不得粉饰功能缺口。

### 7. `[qif]` 配置节

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `output` | string | `"obj/qif"` | QIF 产物根目录（`.arcqif` + `report.json` 在此层）；缺省从固定 `obj/` 派生 |
| `emit_json_report` | bool | `true` | 是否生成 JSON 报告 |
| `keep_json_history` | int | `1` | JSON 报告历史保留份数 |
| `persist_results` | bool | `true` | 是否持久化 `.arcqif`（false 仅控制台/JSON） |
| `log_dir` | string | `"{qif.output}/logs"` | 日志目录 |
| `log_keep_history` | int | `10` | 历史日志保留份数（超过自动清理最旧） |
| `log_level` | string | `"info"` | `trace`/`debug`/`info`/`warn`/`error` |
| `output_format` | string | `human` | 报告输出格式（`human`/`json`/`junit`），可被 `--logger` 覆盖 |
| `max_parallel` | int | `1` | 配合 `--parallel` 时的默认并发度（`>1` 生效；否则不限） |
| `default_timeout` | int | `0` | 默认单测超时毫秒 |
| `fail_on_skip` | bool | `false` | Assert.Skip → 非零退出 |

字段优先级链：`CLI 参数 > [qif] 字段 > 内置默认值`。

### 8. 并行执行（xUnit 子集）与拒绝项

**并行语义（诚实边界）**：

| 规则 | 说明 |
|------|------|
| 默认串行 | 确定性优先；未给 `--parallel` 时不并行 |
| `--parallel` | 以 `[Collection]` / 隐式「每类一集合」为边界：**集间并行、集内串行** |
| `--max-parallel` | `ParallelOptions.MaxDegreeOfParallelism`；覆盖 `[qif].max_parallel` |
| async 套件 | 任一 async Fact/Theory → **整套强制串行**（文档与实现对齐；非有界并行） |
| 失败聚合 | `QIFRunner` Lock 保护计数；退出用 `ShouldFailExit`（失败/错误/属性 Fact-Skip / 可选 FailOnSkip） |

| 项 | 裁决 |
|----|------|
| 运行时反射发现测试 | 拒绝——Arc 永久剔除反射，发现走编译期 registry |
| 默认并行 | 拒绝——默认串行保证确定性；并行为显式 opt-in |
| 测试作为可选旁路 | 拒绝——`arc test` 是默认验证入口与质量闸门 |
| 宣称七层完备 | 拒绝——仅 L1 稳定；L2–L7 为愿景 |

### 9. 覆盖率（与 QIF 正交 · 尚未落地）

覆盖率是**编译/运行层能力**（codegen 插桩），与本框架（测试发现/执行）正交。设计见 [015 references/coverage](015-llvm-backend/references/coverage.md)。

**现状**：`arc test --coverage` CLI 钩子已接线，调用时**明确非零报错**（禁止假绿）。剩余阻塞：codegen/clang 插桩贯通 + `llvm-profdata`/`llvm-cov` 工具链捆绑（见 plan QIF-5）。

## 边界

- **编译器管线**（attr 收集、GenerateTo、合成入口 lower）见 [013](013-compiler-pipeline.md)；本 RFC 只讲 `arc test` 用户面、断言与配置。
- **QIF 产物配置**以手册 [arc.toml 参考](../arc/10-toolchain/arc-toml-reference.md) 为权威。
- **动态测试 host**（测试项目编译为动态库经 `arc-test-host` 加载）、完整 `IClassFixture`/`ICollectionFixture` DI 生命周期不在本设计面内；当前诚实等价：`IQIFOutput` ctor 注入 + `IQIFSetup`/`IQIFTeardown`。
- **覆盖率**机制与格式见 [015 references/coverage](015-llvm-backend/references/coverage.md)；落地前不得宣称 lcov 可用。
- **退出码**：失败/错误/属性 Fact-Skip → 非零；Assert.Skip 默认 exit 0，`--fail-on-skip` / `[qif].fail_on_skip` 时非零。

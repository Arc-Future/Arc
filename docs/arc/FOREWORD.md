# 前言

欢迎阅读 **《Arc 开发者手册》**——面向用 Arc **编写程序**的开发者的官方文档。

Arc 是纯 AOT 编译的系统级语言：强类型、**C# 惯用表面语法**，查询与表达式树在**编译期**展开，运行时只执行已物化的原生代码。本书帮助你安装工具链、掌握语言与标准库、使用领域库（UI / AI / ORM / Web 等），并把示例跑起来。

> **同名消歧**：公开仓为 [Arc-Future/Arc](https://github.com/Arc-Future/Arc)。与 Cratis/Arc 等其它同名项目无关。

## 本书适合谁

| 读者 | 你将获得什么 |
|------|-------------|
| 想用 Arc 写应用的开发者 | 安装、语法、类型/内存/异步、标准库与 CLI |
| 熟悉 C# / .NET 的团队 | 表面语法映射、单一惯用法、与 .NET CLI 对齐的 `arc` 命令 |
| 做桌面 UI / AI / Web / 数据访问的工程师 | 领域库用法与示例路径 |
| 用 AI 辅助写代码的开发者 | 结构化诊断、可预测的单一写法 |

**本书不是**：RFC 全文汇编、编译器/运行时实现手册、自举里程碑记录。设计决策权威仍在仓库 `docs/rfc/`；实现者材料见仓库内其它路径（不进入本发布包）。

## 如何阅读

1. **第一至二章**——定位与 30 分钟内跑通 Hello World  
2. **第三至八章**——语言：语法 → 类型 → 内存 → 对象 → 异步 → 查询  
3. **第九至十章**——标准库导览与 `arc` 工具链  
4. **第十一章**——领域库（UI / Agent / ORM / Web / Net / DI / Chord）  
5. **第十二章**——进阶（诊断、能力、Native、热重载）与设计决策入口  

每章 `INDEX.md` 是小节目录；不必线性通读。

## 约定

| 约定 | 含义 |
|------|------|
| `.as` | Arc 源文件扩展名 |
| `arc` | AOT 编译器 CLI |
| `void Main()` | 程序入口（亦可 `async Task Main()`） |
| `Task<T>` | 异步计算句柄 |
| `Expression<T>` | 编译期表达式树 |
| ✅ / ❌ | 推荐做法 / 常见错误 |

示例尽量可编译；仓库路径：`examples/`、`std/`。版本口径：**0.1**（pre-1.0），不宣称与 C# 完备对等。

## 文档与实现

用户可见行为以本手册与当前 `arc` CLI / `std/` 为准。语义级设计冲突时，以仓库已接受 RFC 为裁决；**本手册保持用法叙事**，不把 RFC 编号目录当作主阅读路径。
